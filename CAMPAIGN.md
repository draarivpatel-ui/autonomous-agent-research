# Campaign decisions and engineering evidence

## Lead architecture decision

Use MuseWeaver and BlastRadius Zero as the primary developer-agent safety story. Their strongest demonstrated feature is executable separation of mathematical correctness and operational authorization. Use AirCast for the privacy and identity story. Use SpatialHand as an inspectable interaction prototype rather than an unverified headset product.

The research papers distinguish actual measurements from simulations, model adapters from model inference, and verified mathematical contracts from arbitrary source programs.

## Flagship changes

MuseWeaver now has a local Z3 verifier, exact BigInt refill arithmetic, bounded seeded tests and isolated off-thread custom execution. API keys are session-only. Edited code no longer inherits a certificate belonging to the bundled implementation.

BlastRadius Zero now has a closed structured action gate, Python/browser parity tests, a locally contract-tested Bedrock adapter and deterministic clean scoring. Fictional gVisor runtimes, destruction receipts and HMAC claims were replaced with honest local SHA-256 diagnostics.

AirCast now corrects its Hamming syndrome table, validates CRC after correction, measures both coded and uncoded channels and bounds waveform allocation. Its faster software profile is benchmarked, not represented as physically validated. Anonymous identity signatures and replay-safe private packets use real WebCrypto.

SpatialHand keeps the pre-existing workspace and renderer improvements. Filter invalid-input handling, pinch cancellation, XR/simulator ownership, missing-pose handling and camera cleanup were strengthened. Hardware and ergonomic claims were narrowed to the evidence actually available.

## Verified rule observations

Kiroween's official rules at [the organizer page](https://kiroween.devpost.com/rules) specify a submission window from October 30 to December 4, 2026, ending at 2 PM Pacific. They require an age-of-majority entrant and substantial Kiro use. A project must be new within the period; pre-existing work must be disclosed. A `.kiro/` directory is required but does not prove usage.

The visible initial commits of MuseWeaver and BlastRadius Zero are dated November 3, 2026. This is repository evidence, not proof that every underlying idea or reused component was newly created then.

The Gemma and ARC Paper Track page titles were publicly readable. Full rules were not inferred from a page title. The AWS MSP search encountered a bot challenge, which was not bypassed. There was no authenticated contest portal action.

## Git and ownership

The four existing remotes resolve to the public `draarivpatel-ui` repositories. The public API did not resolve the requested `Draariv` account during this check. No remote was silently migrated or renamed.

HTTPS push dry-run could not obtain a password, GitHub CLI was unauthenticated and SSH access was denied. Publishing requires an authenticated account with write access to the actual target repositories. The research bundle's new remote must be confirmed or created under that account.

Pre-existing SpatialHand edits were retained in scope. The existing BlastRadius Zero slide-deck PDF was not edited, removed or added to the research bundle. It is tracked in the current flagship baseline.

The current flagship baselines contain some earlier parts of the shared build. No history was rewritten. Remaining local commits cover the current scoped diffs, and the research source manifest records the modules actually measured.
